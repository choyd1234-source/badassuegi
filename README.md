# 녹음 받아쓰기 웹앱

녹음 파일·동영상이나 지금 하는 말을 한국어 텍스트로 바꿔 주는 웹앱이에요.
모든 처리는 각자의 브라우저 안에서 이뤄지고, 녹음과 받아쓴 내용은 어디에도 올라가지 않아요.

Powered by Moonshine AI — 음성 인식 모델은 Moonshine AI Community License를 따라요 (`LICENSE.txt`, `NOTICE.txt`).

## 할 수 있는 것

- **파일 받아쓰기:** mp3·m4a·wav·aac 녹음과 mp4·mov·3gp 동영상. 세 시간짜리도 돼요.
- **실시간 녹음:** 말하는 동안 몇 초 안에 글자가 나와요. 녹음 소리도 함께 저장돼요.
- **내 기록:** 받아쓴 글이 녹음마다 따로 저장돼요. 다시 열어 보기, 이름 바꾸기, 복사, .txt 저장, 삭제를 할 수 있어요.
- **이어서 하기:** 중간에 멈췄거나 페이지가 닫혔으면, 같은 파일을 다시 고르면 멈춘 곳부터 이어서 해요.
- **흐린 곳 표시:** 잘 안 들려서 확실하지 않은 말에 밑줄이 그어져요. 누르면 그 문장부터 다시 들을 수 있어요.
- **Claude로 다듬기:** 받아쓴 글을 Claude에게 보내 앞뒤 흐름에 맞지 않는 낱말만 고치게 해요. 고친 곳은 색으로 표시되고, 받아쓴 글도 그대로 남아요. (이 웹앱에서는 복사해서 Claude 앱에 붙여 넣고, 답을 다시 붙여 넣는 방식이에요.)

## 작게 말하거나 웅얼거린 곳

- 소리가 작은 사람의 말도 놓치지 않도록, 말소리를 찾을 때 소리 크기를 맞춰서 찾아요.
- 음성 인식이 자신 없어 하는 문장은 여러 후보를 견줘 한 번 더 받아써요.
- 그래도 남는 잘못(소리가 비슷한 다른 낱말)은 ‘Claude로 다듬기’로 고칠 수 있어요.

## 인터넷에 올리는 법 (GitHub Pages, 무료)

1. https://github.com 에 로그인하고 저장소를 하나 만들어요 (Public).
2. 저장소 화면에서 **Add file → Upload files**를 눌러, 이 폴더 안의 파일을 **모두** 올리고 **Commit changes**를 눌러요. 한 번에 안 되면 10개씩 나눠 올려요. (파일은 모두 3MB 이하예요.)
   - 폴더 없이 파일만 올리면 돼요. 모든 파일이 맨 위에 있어야 해요.
   - 아이폰: ‘파일’ 앱에서 zip을 눌러 압축을 풀고, 업로드 화면의 파일 선택에서 ‘선택’으로 파일을 전부 고르면 돼요.
3. 저장소의 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 눌러요.
4. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 주소로 열려요.
5. 아이폰 Safari에서 그 주소를 열고 **공유 → 홈 화면에 추가**를 하면 앱처럼 쓸 수 있어요.

## 나중에 새 버전으로 바꿀 때

모델 파일은 그대로 두고 `index.html`과 `worker.js`만 다시 올리면 돼요 (같은 이름이면 덮어써져요).

## 알아 두기

- 처음 한 번 음성 인식 모델(약 71MB)을 받아서 기기에 저장해요. 와이파이에서 여는 걸 권해요.
- 내 기록은 그 기기·그 브라우저에만 저장돼요. 다른 기기에서는 보이지 않으니 중요한 글은 .txt로 저장해 두세요.
- 실시간 녹음은 처음에 마이크 사용 허락을 물어봐요. 화면이 켜져 있고 이 페이지가 앞에 떠 있을 때만 녹음돼요 (아이폰 정책).
- 아이폰 ‘음성 메모’ 녹음은 공유 → ‘파일에 저장’을 한 다음 고르면 돼요.
